Политика конфиденциальности

Женёк — личный бот одного человека (владельца). Других пользователей у него нет.

Какие данные Google он использует

  • Календарь — только чтение (calendar.readonly): чтобы показать владельцу его день.
  • Запись — только в собственный календарь «Женёк» (calendar.app.created): бот создаёт этот календарь сам и пишет в него события только после того, как владелец нажал кнопку подтверждения. В другие календари писать он не может — так устроена сама область доступа Google.
  • Почта — только чтение (gmail.readonly): отправитель, тема и короткий фрагмент новых писем для самого владельца. Тела писем бот не читает и ничего не отправляет.

Где хранятся данные

На частном сервере владельца. Данные не продаются, не используются для рекламы, и бот не обучает на них никаких моделей. Чтобы ответить владельцу, бот обращается к языковым моделям через их API — туда уходит только то, что нужно для ответа (например, события дня, о которых спросил владелец).

Как отозвать доступ

В любой момент: myaccount.google.com/permissions → «zhenya» → «Удалить доступ». Календарь «Женёк» удаляется в настройках Google Календаря.

Zhenya is a private, single-user assistant. It reads the owner's calendar and mail (read-only), writes only to a calendar it created itself and only after the owner confirms, stores data on the owner's private server, and never sells it or uses it to train models; to answer the owner it sends only what the answer needs to a language model API. Access can be revoked at myaccount.google.com/permissions.
